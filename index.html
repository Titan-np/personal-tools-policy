概要

このページは、開発者（GitHub：Titan-np）が個人で利用するために作成したツール（Google Apps Script、スクリプトなど。以下「本ツール」）に共通して適用されるポリシーです。 本ツールは一般向けの提供・配布を行っていません。ソースコードを公開しているものも、開発者本人の利用を目的としています。

外部サービスのアカウントへのアクセスについて

本ツールが Google などの外部サービスと連携する場合は、認可時の画面（GoogleのOAuth同意画面など）に表示される権限の範囲に限りアクセスします。 詳しくはプライバシーポリシーをご覧ください。

プライバシーポリシー

制定日：2026年10月10日

本ツールにおける利用者データ（外部サービスから取得するデータを含む）の取り扱いを、以下のとおり定めます。

1. アクセスするデータ

本ツールは、利用者の許可を得たうえで、各ツールの機能に必要な範囲に限り外部サービスのデータへアクセスします。アクセスする範囲は、認可時の画面に表示されます。

2. 利用目的

取得したデータは、各ツールの機能を提供するためにのみ利用します。

3. データの保存

  • 認証情報（トークンなど）は、利用者自身のアカウントや実行環境内（Google Apps Script のプロパティなど）に保存します。
  • 取得したデータは、各ツールの機能に必要なサービスの間でのみ送受信します。
  • 開発者が管理するサーバーへ、データを送信・保存することはありません。

4. 第三者への提供

取得したデータを第三者へ提供・販売することはありません。また、広告の目的には利用しません。

5. Google API サービスのユーザーデータに関するポリシーの遵守

Google API を利用するツールにおける、Google APIから取得した情報の利用と他のアプリへの転送は、 Google API サービスのユーザーデータに関するポリシー（限定使用の要件を含む）に従います。

6. アクセス権の取り消し

本ツールへのアクセス権は、各サービスのアカウント設定からいつでも取り消せます。 Googleの場合は、Googleアカウントの「サードパーティ製のアプリとサービス」から取り消せます。

7. 本ポリシーの変更

本ポリシーの内容を変更する場合は、このページを更新します。

5. 免責

6. 外部サービスの利用

本ツールが利用する外部サービスには、各サービスの利用規約が適用されます。

7. 本規約の変更

本規約の内容を変更する場合は、このページを更新します。
